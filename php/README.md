# Campus Maintenance Fault Reporting System

## Overview

The Campus Maintenance Fault Reporting System is a web application developed using HTML, CSS, JavaScript, PHP and MySQL. It enables students to report maintenance issues around the campus through an online form helping the campus managment to idenitfy faults and act accordindly.

---

## Features

- Home page
- Fault reporting form
- JavaScript validation
- Live report preview
- Character counter
- Responsive design
- PHP form processing
- MySQL database storage

## Installation

1. Install XAMPP.
2. Copy the project folder into:

```
htdocs/
```

3. Start Apache and MySQL.

4. Open phpMyAdmin.

5. Import database.sql.

6. Visit

```
http://localhost/Campus-Maintenance-System/
```
